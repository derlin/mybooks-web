# MyBooks Web

Web implementation of MyBooks, which supersedes https://github.com/derlin/mybooks-android.

> [!warning] The webapp is only forward-compatible: when opening MyBooks Web for the first time, your data will be migrated to the new format. However, you will not be able to open your data in MyBooks Android after that.

MyBooks allows you to track the books you read, and saves everything into a JSON file in your Dropbox account. You can download or access the JSON at any point, and use the Dropbox history to recover any change.

It is simple, yet has all the fields and features you need.
